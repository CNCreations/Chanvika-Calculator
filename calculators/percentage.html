Percentage Formulas

To find what percentage one number is of another:

Percentage = (Number ÷ Base) × 100

To calculate a percentage of a number:

Percentage Value = Number × Percentage ÷ 100

To calculate percentage increase or decrease:

Percentage Change = (New Value − Original Value) ÷ Original Value × 100

Percentage Calculation Examples

Example 1: What is 25 out of 200?

(25 ÷ 200) × 100 = 12.50%

Example 2: What is 20% of ₹500?

₹500 × 20 ÷ 100 = ₹100

Example 3: Price increased from ₹500 to ₹650

((₹650 − ₹500) ÷ ₹500) × 100 = 30% increase

Percentage vs Percentage Change

A percentage and a percentage change are not always the same thing. Percentage usually compares one value with a base, while percentage change compares a new value with an original value.

For example, an increase from ₹500 to ₹650 represents a 30% increase because the ₹150 increase is measured against the original ₹500.

Frequently Asked Questions

What is 10% of 1,000?

10% of 1,000 is 100.

How do I calculate percentage?

Divide the number by the base or total and multiply the result by 100.

How do I calculate percentage increase?

Subtract the original value from the new value, divide the difference by the original value and multiply by 100.

How do I calculate percentage decrease?

Use the same percentage-change formula. If the new value is lower than the original value, the result will be negative, indicating a decrease.
